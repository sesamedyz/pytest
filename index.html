练习示例

1. 打印问候语

学习如何用 Python 显示一句简单的问候。

print("你好，Python 小朋友！")

2. 计算喜欢的数字

让孩子尝试把数字相加，认识变量和数学运算。

num = 7 result = num + 3 print(result)

3. 简单猜数字

用输入和条件判断创建一个小游戏。

answer = 8 guess = int(input("猜一个数字：")) if guess == answer: print("太棒了，答对了！") else: print("再试一次吧！")

快速开始步骤

1. 安装 Python

在电脑上安装 Python，推荐使用最新稳定版本。也可以使用在线编程平台直接练习。

2. 运行第一个程序

打开编辑器，复制示例代码，按运行按钮查看输出结果。

3. 继续探索

尝试修改示例、增加新功能，让编程变成创造故事和游戏的工具。
