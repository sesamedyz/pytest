一yī 个gè 关guān 于yú 陪péi 伴bàn 的de 故gù 事shì

===== Page 1: 月yuè亮liàng船chuán的de工gōng作zuò =====
从cóng前qián，在zài一yī片piàn很hěn高gāo的de天tiān上shàng，有yǒu一yī只zhǐ弯wān弯wān的de月yuè亮liàng船chuán。
每měi天tiān晚wǎn上shàng，月yuè亮liàng船chuán都dōu会huì慢màn慢màn地dì从cóng东dōng边biān划huà到dào西xī边biān，给gěi大dà地dì洒sǎ下xià柔róu和hé的de银yín光guāng。

===== Page 2: 月yuè亮liàng船chuán的de烦fán恼nǎo =====
月yuè亮liàng船chuán很hěn喜xǐ欢huān自zì己jǐ的de工gōng作zuò，但dàn他tā有yǒu一yī个gè小xiǎo小xiǎo的de烦fán恼nǎo——他tā太tài安ān静jìng了le。
漫màn漫màn长zhǎng夜yè，只zhǐ有yǒu风fēng儿ér偶ǒu尔ěr路lù过guò，跟gēn他tā说shuō一yī两liǎng句jù话huà，然rán后hòu又yòu匆cōng匆cōng飞fēi走zǒu了le。

"要yào是shì有yǒu人rén能néng陪péi我wǒ一yī起qǐ划huà船chuán就jiù好hǎo了le。"月yuè亮liàng船chuán轻qīng轻qīng叹tàn了le口kǒu气qì。

===== Page 3: 小xiǎo闪shǎn出chū场chǎng =====
就jiù在zài这zhè时shí，一yī颗kē小xiǎo小xiǎo的de星xīng星xīng从cóng云yún朵duǒ后hòu面miàn探tàn出chū了le头tóu。她tā叫jiào小xiǎo闪shǎn，是shì天tiān上shàng最zuì小xiǎo最zuì胆dǎn怯qiè的de星xīng星xīng。
别bié的de星xīng星xīng都dōu大dà大dà方fāng方fāng地dì挂guà在zài天tiān空kōng中zhōng间jiān，闪shǎn闪shǎn发fā亮liàng，可kě小xiǎo闪shǎn总zǒng是shì躲duǒ在zài云yún朵duǒ后hòu面miàn，觉jué得dé自zì己jǐ太tài小xiǎo了le，没méi人rén会huì注zhù意yì到dào她tā。

"你nǐ……你nǐ在zài叹tàn气qì吗ma？"小xiǎo闪shǎn小xiǎo声shēng地dì问wèn。

===== Page 4: 月yuè亮liàng船chuán的de邀yāo请qǐng =====
月yuè亮liàng船chuán吓xià了le一yī跳tiào，然rán后hòu笑xiào了le：
"是shì呀ya，长zhǎng夜yè漫màn漫màn，有yǒu点diǎn孤gū单dān。你nǐ愿yuàn意yì坐zuò到dào我wǒ的de船chuán上shàng来lái吗ma？"

小xiǎo闪shǎn犹yóu豫yù了le一yī下xià："可kě是shì我wǒ太tài小xiǎo了le，我wǒ的de光guāng也yě很hěn微wēi弱ruò……"

"没méi关guān系xì呀ya！船chuán大dà船chuán小xiǎo都dōu能néng划huà，光guāng强qiáng光guāng弱ruò都dōu能néng亮liàng。来lái吧ba！"月yuè亮liàng船chuán温wēn柔róu地dì说shuō。

===== Page 5: 船chuán上shàng的de美měi景jǐng =====
小xiǎo闪shǎn鼓gǔ起qǐ勇yǒng气qì，轻qīng轻qīng地dì跳tiào上shàng了le月yuè亮liàng船chuán的de弯wān弯wān船chuán身shēn。哇wa——从cóng船chuán上shàng看kàn下xià去qù，整zhěng个gè世shì界jiè好hǎo美měi呀ya！
山shān峦luán像xiàng睡shuì着zhe的de巨jù兽shòu，河hé流liú像xiàng闪shǎn闪shǎn的de丝sī带dài，小xiǎo镇zhèn里lǐ的de灯dēng火huǒ像xiàng一yī颗kē颗kē橘jú黄huáng色sè的de小xiǎo糖táng豆dòu。

"好hǎo漂piāo亮liàng！"小xiǎo闪shǎn忍rěn不bù住zhù轻qīng轻qīng叫jiào了le起qǐ来lái，她tā的de光guāng也yě亮liàng了le一yī点diǎn点diǎn。

月yuè亮liàng船chuán笑xiào着zhe说shuō："你nǐ看kàn，你nǐ的de光guāng并bìng不bù弱ruò嘛ma。"

===== Page 6: 一yī起qǐ讲jiǎng故gù事shì =====
那nà一yī夜yè，月yuè亮liàng船chuán和hé小xiǎo闪shǎn一yī起qǐ慢màn慢màn地dì划huà过guò天tiān空kōng。
小xiǎo闪shǎn给gěi月yuè亮liàng船chuán讲jiǎng天tiān上shàng星xīng星xīng们men的de故gù事shì——谁shuí爱ài跳tiào舞wǔ，谁shuí爱ài捉zhuō迷mí藏cáng，谁shuí总zǒng是shì打dǎ瞌kē睡shuì。
月yuè亮liàng船chuán给gěi小xiǎo闪shǎn讲jiǎng大dà地dì上shàng的de故gù事shì——哪nǎ条tiáo河hé最zuì温wēn柔róu，哪nǎ座zuò山shān最zuì沉chén稳wěn，哪nǎ个gè小xiǎo镇zhèn的de孩hái子zi最zuì爱ài笑xiào。

风fēng儿ér路lù过guò的de时shí候hòu，听tīng到dào了le他tā们men的de笑xiào声shēng，忍rěn不bù住zhù也yě留liú下xià来lái听tīng了le一yī会huì儿ér。

===== Page 7: 天tiān亮liàng道dào别bié =====
不bù知zhī不bù觉jué，天tiān边biān泛fàn起qǐ了le淡dàn淡dàn的de橘jú红hóng色sè。新xīn的de一yī天tiān要yào来lái了le。

"我wǒ要yào回huí去qù啦la。"小xiǎo闪shǎn有yǒu点diǎn不bù舍shě地dì说shuō。

"明míng天tiān晚wǎn上shàng再zài来lái吧ba！"月yuè亮liàng船chuán说shuō，"我wǒ每měi晚wǎn都dōu在zài这zhè里lǐ。"

小xiǎo闪shǎn用yòng力lì点diǎn了le点diǎn头tóu，然rán后hòu轻qīng轻qīng地dì从cóng船chuán边biān跳tiào回huí云yún朵duǒ里lǐ。但dàn她tā不bù再zài躲duǒ在zài最zuì深shēn处chù了le——她tā选xuǎn了le一yī片piàn薄báo薄báo的de云yún，刚gāng好hǎo能néng让ràng她tā小xiǎo小xiǎo的de光guāng透tòu出chū来lái。

===== Page 8: 不bù再zài孤gū单dān =====
从cóng那nà以yǐ后hòu，每měi天tiān晚wǎn上shàng，小xiǎo闪shǎn都dōu会huì准zhǔn时shí跳tiào上shàng月yuè亮liàng船chuán。有yǒu时shí候hòu还hái会huì带dài上shàng两liǎng三sān颗kē别bié的de星xīng星xīng朋péng友yǒu一yī起qǐ来lái。

月yuè亮liàng船chuán再zài也yě不bù孤gū单dān了le，而ér小xiǎo闪shǎn呢ne，也yě不bù再zài觉jué得dé自zì己jǐ太tài小xiǎo了le——
因yīn为wèi她tā发fā现xiàn，陪péi伴bàn本běn身shēn就jiù是shì一yī种zhǒng光guāng。
